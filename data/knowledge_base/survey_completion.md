# Client Unable to Complete Survey

## Problem Description
A client is unable to complete a survey due to missing answer options, errors, or other issues. This requires gathering additional information to diagnose and resolve the problem.

## Resolution Steps

1. **Gather information from the client**
   - Is the survey part of the client portal or learning material?
   - What lesson or program is the survey associated with?
   - Are there any specific error messages displayed?
   - Which answer options appear to be missing?

2. **Attempt to reproduce the issue**
   - If possible, access the same survey in the same context
   - Document the exact steps and any errors observed

3. **Provide troubleshooting steps**
   - Suggest refreshing the browser
   - Suggest clearing cache or trying a different browser
   - If the issue persists, escalate to L&D or development team

4. **Escalate if needed**
   - If the survey has a technical defect, create a ticket for the development team
   - Include client details (anonymized if appropriate), program/lesson name, and description of the issue

## Response Template

"I understand it's frustrating when you can't complete a survey due to missing answer options, and I'd like to help resolve this for you. Could you provide more information?"

## Internal Notes

- Always gather: survey location (portal vs. learning), lesson/program name, and any error messages.
- Document recurring survey issues for pattern analysis.
- Some surveys may have validation rules that prevent certain inputs; verify expected behavior before escalating.
