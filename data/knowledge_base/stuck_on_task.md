# Stuck on a Task

## Problem Description
A client reports being unable to proceed past a specific task in their workplan or course on the Operation HOPE Client Portal. The task may appear stuck, unresponsive, or produce an error when attempting to move forward.

## Resolution Steps

1. **Gather information from the client:**
   - What is the name of the task or program they are working on?
   - Are there any error messages or prompts appearing on screen?
   - What exactly happens when they try to move forward? (e.g., nothing happens, page freezes, error displayed)

2. **Basic troubleshooting:**
   - Ask the client to refresh the page and try again
   - Clear browser cache and retry
   - Try in incognito or private browsing mode
   - Try a different browser

3. **If the issue persists:**
   - Request a screenshot of the task and any error messages
   - Note the client's browser and device information
   - Escalate to the appropriate team based on whether the task is in the portal workplan or LMS course

## Response Template

"We would like to help you move forward with your task. Could you please provide the following details so we can assist you better: 1) What is the name of the task or program you are working on? 2) Are you seeing any error messages or prompts on screen? 3) What happens when you try to move forward (e.g., nothing happens, the page freezes, or an error appears)? In the meantime, please try refreshing the page, clearing your browser cache, and attempting the task in an incognito or private browsing window."

## Internal Notes

- This is a triage article. The resolution depends on identifying the specific task and the nature of the block.
- Common causes include: incomplete prerequisite tasks, browser cache issues, LMS synchronization delays, or portal bugs.
- If the task is in the LMS, check the client's course enrollment and completion status.
- If the task is in the portal workplan, verify the task configuration in Dynamics365.
