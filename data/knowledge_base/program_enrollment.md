# Program Enrollment for Client

## Problem Description
A client needs to be enrolled in a specific program in Dynamics 365. This involves creating a new program enrollment record and associating it with the correct coach and program details.

## Resolution Steps

1. **Search for the client in Dynamics 365**
   - Open Dynamics 365 and search for the client by name or email
   - Open the client's profile

2. **Create a new program enrollment**
   - Navigate to the Programs tab
   - Click "+ New Program Enrollment"

3. **Enter enrollment details**
   - Enter the coach name
   - Select the program name
   - Set "Working with Coach" to "Yes"
   - Fill in any other required fields
   - Click Save

4. **Verify and update HI Location**
   - Use Advanced Find to locate the new enrollment
   - Verify the enrollment was created correctly
   - Update the HI Location field as needed for reporting

5. **Confirm completion**
   - Ensure the client can see the program in their portal
   - Verify the coach assignment is correct

## Response Template

"The client has been enrolled in the requested program. Their coach and program details are updated in Dynamics."

## Internal Notes

- "Working with Coach" must be set to "Yes" for proper reporting and dashboard visibility.
- HI Location is often updated separately via Advanced Find.
- Verify the client has portal access before confirming enrollment visibility.
