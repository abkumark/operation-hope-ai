# Ticket Lacks Sufficient Information

## Problem Description
A support ticket has been submitted but does not contain enough detail to diagnose or resolve the issue. The ticket may be vague, missing context, or lack specific information about the problem.

## Resolution Steps

1. **Review the ticket**
   - Identify what information is missing
   - Determine which questions will help narrow down the issue

2. **Send a request for more information**
   - Use the response template to ask targeted questions
   - Request specifics about: course/module, error messages, and when the issue occurs

3. **Set expectations**
   - Let the client know that additional details will help resolve the issue more quickly
   - Provide a timeframe for when they can expect a follow-up once information is received

4. **Follow up**
   - If no response is received within a reasonable timeframe, send a reminder
   - Consider closing or pausing the ticket with a note if the client does not respond

## Response Template

"To assist you effectively, could you please provide more details about the problem you're encountering? Specifically: Are you facing difficulties accessing a particular course or module? Is there a specific error message appearing? At what point does the issue occur?"

## Internal Notes

- Vague tickets often indicate the client may not know how to describe the issue; guide them with specific questions.
- Document common information gaps to improve ticket templates or intake forms.
- Avoid making assumptions; always confirm details before attempting resolution.
