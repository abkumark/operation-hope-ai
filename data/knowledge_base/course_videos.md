# Course Videos Not Working

## Problem Description
A client reports that course videos are not loading, playing, or displaying correctly on the Operation HOPE learning platform. This is typically caused by browser cache issues, outdated browsers, or browser compatibility problems.

## Resolution Steps

### Google Chrome

1. **Clear browser cache:**
   - Click the three dots menu (top-right corner)
   - Select **More Tools** > **Clear Browsing Data**
   - Check **Cached images and files**
   - Click **Clear data**
2. **Try Incognito mode:**
   - Press `Ctrl+Shift+N` (Windows) or `Cmd+Shift+N` (Mac)
   - Navigate to the course and attempt to play the video
3. **Update the browser:**
   - Click the three dots menu > **Help** > **About Google Chrome**
   - Allow any available updates to install and restart the browser
4. **Try a different browser:**
   - If the issue persists in Chrome, try Firefox, Edge, or Safari

### Safari (Mac)

1. **Clear browser cache:**
   - Go to **Settings** (or **Preferences**) > **Advanced**
   - Check **Show Develop menu in menu bar**
   - Click the **Develop** menu > **Empty Caches**
2. **Try Private Browsing:**
   - Click **File** > **New Private Window**
   - Navigate to the course and attempt to play the video
3. **Update Safari:**
   - Go to **System Settings** > **General** > **Software Update**
   - Install any available macOS updates (Safari updates are included with macOS)

## Response Template

"We understand you are having trouble with course videos. Please try the following steps: First, clear your browser cache. In Chrome, click the three dots menu, then More Tools, then Clear Browsing Data, select Cached images and files, and click Clear. Next, try opening the course in an incognito or private browsing window. Also, make sure your browser is up to date. If the issue continues, please try using a different browser. Let us know if the problem persists after trying these steps."

## Internal Notes

- Most video playback issues are resolved by clearing the browser cache.
- If the issue persists across multiple browsers and devices, this may indicate a problem with the course content itself. Escalate to the L&D team for investigation.
- Ensure the client has a stable internet connection, as video streaming requires sufficient bandwidth.
- Some corporate networks may block video streaming. Suggest trying on a personal network if applicable.
