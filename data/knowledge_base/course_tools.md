# Course Tools or Resources Not Functioning

## Problem Description
A client reports that course tools, resources, or interactive elements are not functioning correctly. This may include calculators, worksheets, links, or other embedded content that fails to load or operate as expected.

## Resolution Steps

1. **Gather information**
   - Course name and module/section where the issue occurs
   - Description of the specific tool or feature that is not working
   - Screenshot if the client can provide one

2. **Provide troubleshooting steps to the client**
   - Refresh the browser and reload the page
   - Clear the browser cache
   - Disable browser extensions (especially ad blockers)
   - Try a different browser or device

3. **If issue persists**
   - Document the details and escalate to L&D or development team
   - Include: course name, module, tool/feature description, and client's browser/device info

4. **Follow up**
   - If a known issue exists, provide the client with a workaround or expected resolution timeline

## Response Template

"I understand you're experiencing issues with [specific tool or feature]. Here are some troubleshooting steps: 1) Refresh your browser and reload the page. 2) Clear your browser cache. 3) Disable any browser extensions, especially ad blockers. 4) Try a different browser or device. If the issue continues, please let us know the course name and module where this occurs, and we'll investigate further."

## Internal Notes

- Ad blockers and aggressive browser extensions often interfere with course tools.
- Document which courses and tools have recurring issues for prioritization.
- Provide alternative access (e.g., PDF version) when available for critical content.
